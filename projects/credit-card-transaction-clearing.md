# Credit Card Transaction Clearing

**Technologies:** Python, Java, PL/SQL, Linux Shell

## Problem

Daily card settlement operations required accurate processing and reconciliation of high-volume transaction logs.

## Work

Built automation for parsing, cleansing, and reconciling transaction records, with validation checks and anomaly diagnostics. Supported batch operations and security controls for settlement workflows.

## Result

The CV reports a 40% reduction in operational turnaround time and zero record mismatches in monitored daily settlement batches.

This is a high-level portfolio summary. It excludes transaction data, customer information, and internal system details.
