# Banking Settlement and Reconciliation

**Technologies:** Java, PL/SQL, Oracle 19c, Oracle GoldenGate 19c

## Problem

High-volume, time-sensitive settlement and reconciliation workloads needed dependable processing across multiple banking rails.

## Work

Built and maintained backend services and database performance improvements for clearing, dispute-resolution, and ledger-balancing workflows. Work included execution-plan analysis, index partitioning, query tuning, and real-time data replication.

## Result

Supported UPI, IMPS, and RTGS operations under strict availability requirements. The CV reports 99.99%+ operational availability and reduced peak-window timeout spikes.
