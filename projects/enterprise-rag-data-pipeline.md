# Enterprise RAG Data Pipeline and Vector Sync

**Technologies:** Python, FastAPI, LangChain, LlamaIndex, vector databases, CDC

## Problem

Enterprise knowledge was spread across unstructured documentation and live relational records, making it difficult to provide timely, context-aware retrieval.

## Work

Designed an asynchronous ingestion and chunking pipeline to prepare documentation and relational data for embedding and semantic retrieval. The work connected data ingestion and synchronization with downstream LLM/RAG workflows.

## Result

Enabled low-latency semantic retrieval and context-aware LLM querying across the indexed information.

This is a high-level portfolio summary. It excludes production data, customer information, and internal architecture details.
